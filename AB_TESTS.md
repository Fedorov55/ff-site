## Тест 4: Короткий vs длинный первый экран
**Страница:** index.html (Hero)
**Элемент:** Hero-секция

| Вариант | Описание |
|---|---|
| A (контроль) | Полный Hero: H1 + подзаголовок + 3 пункта + CTA + микродоказательство |
| B | Короткий Hero: H1 + CTA + микродоказательство (без пунктов) |

**Метрика:** bounce rate, время на странице, CTR CTA
**Длительность:** 2 недели

---

## Как запускать

1. Использовать Яндекс.Метрику (цели настроены в коде)
2. Разделить трафик 50/50 через `?variant=A` / `?variant=B`
3. Собирать данные минимум 2 недели
4. Принимать решение по конверсии (не по CTR)

## Техническая реализация (опционально)

Добавить в `script.js`:
```js
const variant = new URLSearchParams(location.search).get('variant') || 'A';
document.body.dataset.variant = variant;
// показывать/скрывать элементы по variant
```
