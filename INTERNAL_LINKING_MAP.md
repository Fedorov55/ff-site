# Карта внутренней перелинковки F&F

> Принцип: интент → следующий логичный шаг.
> Каждая страница должна вести пользователя к следующему шагу в воронке.

## Типы страниц и правила перелинковки

| Тип | Правило | Пример |
|-----|---------|--------|
| Коммерческая | → калькулятор / заявка / сравнение | support.html → services.html#calculator |
| Информационная | → коммерческая или лид-магнит | blog/pochemu-1c-tormozit.html → servers.html |
| Сравнительная | → коммерческая + кейсы | compare.html → support.html + cases.html |
| Аудиенсная | → релевантные услуги | for-owner.html → support.html, servers.html |
| Болевая | → решение + калькулятор | pain-1c-slow.html → servers.html |
| Лид-магнит | → коммерческая (мягкий) | lead-audit.html → audit.html |
| Кейс | → коммерческая + все кейсы | cases/office-support.html → support.html |
| Гео | → основная услуга | geo/support-kazan.html → support.html |

## 9. Базовые правила перелинковки

1. **Каждая страница** должна иметь минимум 3 внутренние ссылки на релевантные страницы
2. **Коммерческие страницы** — ссылка на калькулятор/заявку в каждом блоке
3. **Информационные страницы** — ссылка на коммерческую страницу в конце + в контексте
4. **Сравнительные страницы** — ссылка на коммерческую + кейсы
5. **Аудиенсные страницы** — ссылки на 3-4 релевантные услуги
6. **Болевые страницы** — ссылка на решение + калькулятор
7. **Лид-магниты** — мягкая ссылка на коммерческую (не в лоб)
8. **Кейсы** — ссылка на услугу + все кейсы
9. **Гео-страницы** — ссылка на основную услугу + контакты
10. **Блог** — ссылка на коммерческую + смежные статьи

### Анкоры: правила

- Использовать естественные анкоры, не «нажмите здесь»
- Анкор должен описывать целевую страницу
- Не использовать одинаковые анкоры для разных целей
- Максимум 5-7 внутренних ссылок на страницу (кроме навигации/футера)
- Ссылки в тексте — подчёркнутые, цвет `var(--gold)`

### Приоритеты внедрения

1. **Высокий:** Коммерческие страницы → калькулятор/заявка/сравнение
2. **Высокий:** Информационные (блог) → коммерческая/лид-магнит
3. **Средний:** Сравнительные → коммерческая + кейсы
4. **Средний:** Аудиенсные → релевантные услуги
5. **Низкий:** Болевые, лид-магниты, кейсы, гео — уже частично сделано
