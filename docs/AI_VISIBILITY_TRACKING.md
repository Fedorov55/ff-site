# Отслеживание видимости в Алисе и AI Overviews (2026)

## Яндекс Вебмастер
- **Поисковые запросы:** Вебмастер → Поиск → Запросы → смотреть позиции и CTR.
- **Алиса:** Вебмастер → Поиск → «Поиск с Алисой» — показывает, по каким запросам Алиса цитирует сайт.
- **Индексация:** Вебмастер → Индексирование → страницы в поиске.
- **Качество:** Вебмастер → Диагностика → рекомендации по улучшению.

## Google Search Console
- **Performance:** Search Console → Performance → Queries → фильтр по «AI Overviews» (если доступно).
- **Indexing:** Coverage → страницы в индексе.
- **Rich Results:** Enhancements → FAQ, Breadcrumb, Organization.

## Ручной мониторинг
1. **Алиса (Яндекс):** задавать вопросы в Алисе («сколько стоит сисадмин в Казани», «IT-аутсорсинг Казань») и проверять, цитирует ли она F&F.
2. **Google AI Overviews:** искать запросы в Google и смотреть, появляется ли сайт в AI-блоке.
3. **ChatGPT / Perplexity:** проверять цитирование бренда в ответах на вопросы по IT-аутсорсингу в Казани.

## Фиксация упоминаний бренда и цитирований
- **Таблица:** дата, запрос, площадка (Алиса/Google/ChatGPT), цитировался ли сайт, позиция в выдаче, скриншот.
- **Инструменты:** Яндекс.Вебмастер, Google Search Console, ручной мониторинг.
- **Частота:** 1 раз в месяц (или после каждого обновления контента).

## Рекомендации для F&F
1. Регулярно проверять запросы «сисадмин Казань», «IT-аутсорсинг Казань», «сервер под ключ Казань» в Алисе и Google.
2. Обновлять контент и даты (сигнал свежести).
3. Добавлять answer-first абзацы и FAQPage schema (уже частично сделано).
4. Мониторить CTR и время на сайте в GA4/Yandex.Metrika.
