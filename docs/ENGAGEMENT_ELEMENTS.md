# Элементы для увеличения времени на сайте и глубины — F&F

## 1. Интерактивный квиз «Узнайте стоимость IT-поддержки»
- **Страница:** `index.html`, `services.html`
- **Зачем:** пользователь отвечает на 3–5 вопросов (количество компьютеров, серверов, нужен ли 1С) и получает ориентировочную стоимость. Увеличивает вовлечённость на 2–3 минуты.

## 2. Калькулятор экономии (штатный vs F&F)
- **Страница:** `prices.html`, `compare/compare.html`
- **Зачем:** интерактивный расчёт показывает экономию в месяц/год и срок окупаемости. Уже реализован, можно добавить на страницы сравнения.

## 3. Чек-лист «Готовность IT-инфраструктуры»
- **Страница:** `audits/audit.html`, `services.html`
- **Зачем:** пользователь отмечает пункты (бэкапы, мониторинг, SLA) и видит результат. Увеличивает время на странице и собирает лиды.

## 4. Прогресс-бар «вы здесь»
- **Страница:** длинные страницы (services, support, servers, case pages)
- **Зачем:** визуальный индикатор прогресса чтения (линия сверху). Снижает отказы, показывает, что страница не бесконечная.

## 5. Мини-оглавление (sticky)
- **Страница:** `services.html`, `support.html`, `servers.html`, `compare/compare.html`
- **Зачем:** якорная навигация по секциям (Цены, FAQ, Калькулятор, Сравнение). Уже частично реализовано (quick-nav). Расширить на все длинные страницы.

## 6. Блок «Что будет дальше»
- **Страница:** конец каждой важной секции
- **Зачем:** после FAQ — «Не нашли ответ? Напишите в Telegram →». После кейсов — «Хотите такой же результат? Рассчитать стоимость →». Увеличивает глубину просмотра.

## 7. Визуальные якоря (иконки, цифры, диаграммы)
- **Страница:** `services.html`, `cases.html`, `index.html`
- **Зачем:** иконки в карточках, фоновые цифры, мини-графики (uptime, экономия). Уже частично есть. Добавить на остальные страницы.
