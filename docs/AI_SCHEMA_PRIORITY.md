# Schema и цитирование в ИИ — F&F

## Что важнее для ИИ

### 1. Позиция в выдаче (критично)
- ИИ-системы (Алиса, Google AI Overviews) цитируют страницы из **топ-10** обычной выдачи.
- Без позиции в топе разметка не поможет.
- **Вывод:** сначала классическое SEO, потом schema.

### 2. Качество и соответствие тексту (высоко)
- Schema должна **точно совпадать** с видимым текстом на странице.
- ИИ проверяет согласованность: если FAQPage говорит одно, а текст другое — не цитирует.
- **Вывод:** schema без качественного текста бесполезна.

### 3. Наличие разметки (средне)
- Разметка помогает ИИ **извлечь** факты, но не гарантирует цитирование.
- Без разметки ИИ может извлечь факты из текста, но медленнее и менее точно.
- **Вывод:** разметка — усилитель, а не основа.

## Как каждый тип влияет на цитирование

| Тип | Влияние на цитирование | Что важно |
|-----|------------------------|-----------|
| **FAQPage** | Высокое — ИИ любит готовые Q&A | Вопросы должны совпадать с реальными запросами, ответы короткие и точные |
| **HowTo** | Среднее — ИИ цитирует шаги | Шаги должны быть конкретными и последовательными |
| **Service** | Среднее — ИИ использует для описания услуги | name, description, price, areaServed должны быть точными |
| **Review** | Высокое — ИИ использует для доверия | Только реальные отзывы, правильная привязка к Service/Organization |
| **BreadcrumbList** | Низкое — помогает навигации | Корректная иерархия, абсолютные URL |
| **Organization** | Высокое — ИИ использует для идентификации бренда | name, url, logo, telephone, address, taxID, description |

## Практические рекомендации для F&F
1. **Сначала позиция** — без топ-10 schema не поможет.
2. **Качество текста** — answer-first, конкретные цифры, честные формулировки.
3. **Точное соответствие** — schema должна совпадать с текстом.
4. **FAQPage** — вопросы как реальные запросы («сколько стоит сисадмин в Казани»), ответы 1–2 предложения.
5. **Service** — цена, описание, зона работы (Казань, Татарстан, Россия).
6. **Review** — только реальные отзывы с согласия клиентов.
7. **HowTo** — шаги должны быть на странице и совпадать с разметкой.

## Приоритет
1. Высокий: позиция в топ-10, качество текста, FAQPage + Service.
2. Средний: HowTo, Review, BreadcrumbList.
3. Низкий: точная структура llms.txt.
