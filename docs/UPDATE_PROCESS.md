## 3. Как фиксировать изменения

1. **Создать ветку:** `git checkout -b update/q4-2026-numbers`.
2. **Обновить цифры** в указанных файлах.
3. **Запустить проверки:** `python scripts/check-site.py`.
4. **Обновить дату** в примечаниях: «По данным открытых вакансий Казани на [месяц] 2026».
5. **Закоммитить:** `git commit -m "content: update market numbers Q4 2026"`.
6. **Запушить и создать PR** (или напрямую в main).
7. **Обновить `docs/DESIGN_AUDIT.md`** — отметить дату обновления.

## 4. Как не сломать существующий контент

- **Не меняйте структуру HTML** — только текст внутри тегов.
- **Не трогайте классы и атрибуты** — только числа и формулировки.
- **Используйте поиск по точной фразе** (например, «80 000») перед заменой.
- **Проверяйте контекст** — одна и та же цифра может означать разное в разных местах.
- **Запускайте `check-site.py`** после каждого изменения.
- **Делайте бэкап** перед массовой заменой (git stash или отдельная ветка).
- **Тестируйте на локальном сервере** перед пушем.
