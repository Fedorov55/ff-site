# Аудит мобильной версии — F&F Site (поведенческие факторы)

## 1. Длинные заголовки
- **Проблема:** `clamp(34px,4.6vw,56px)` на мобильных может давать 3–4 строки, увеличивая скролл.
- **Рекомендация:** На мобильных (<480px) уменьшить до `clamp(28px,8vw,40px)`. Добавить `text-wrap: balance`.
- **Эффект:** меньше скролла, быстрее восприятие.

## 2. Формы
- **Проблема:** Поля ввода 48px высоты, но на мобильных клавиатура занимает половину экрана.
- **Рекомендация:** Использовать `inputmode="numeric"` для телефонов, `autocomplete` для автозаполнения. Добавить `scroll-margin-top` для якорей.
- **Эффект:** меньше ошибок при вводе, выше конверсия.

## 3. Кнопки
- **Проблема:** Кнопки в ряд на мобильных могут быть узкими.
- **Рекомендация:** На <680px делать кнопки на всю ширину (`width:100%`). Минимальная высота 48px (уже есть). Добавить `padding-inline: 16px`.
- **Эффект:** удобнее нажимать, меньше промахов.

## 4. Скролл длинных страниц
- **Проблема:** Страницы с 10+ секциями — пользователь устаёт.
- **Рекомендация:** Добавить «Быстрый переход» (sticky-бар с якорями) на все длинные страницы. Сократить секции до 5–6 на страницу. Использовать `content-visibility: auto` для секций.
- **Эффект:** меньше отказов, больше глубина.

## 5. Скорость доступа к телефону и заявке
- **Проблема:** Телефон в хедере скрывается на мобильных (`.header__phone{display:none}`).
- **Рекомендация:** Добавить sticky bottom bar с кнопками «Позвонить» и «Рассчитать» (уже есть `.mobile-bottom-bar`). Убедиться, что он появляется при скролле > 45%.
- **Эффект:** мгновенный доступ к контакту, рост звонков.

## Приоритетные правки
1. **Высокий:** Убедиться, что `.mobile-bottom-bar` работает на всех страницах (уже есть).
2. **Высокий:** Добавить `inputmode` и `autocomplete` в формы.
3. **Средний:** Уменьшить заголовки на мобильных.
4. **Средний:** Добавить sticky quick-nav на длинные страницы.
5. **Низкий:** Проверить `content-visibility` для производительности.
