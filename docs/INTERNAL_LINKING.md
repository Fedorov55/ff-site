# Система внутренней перелинковки — F&F Site

## Принципы
- Каждая страница должна иметь 2–3 логических «следующих шага».
- Анкоры — естественные, не переспамленные («Подробнее», «Тарифы», «Кейсы»).
- Связи: информационные → коммерческие → сравнение/кейсы/калькулятор.

## Схема связей

### Информационные страницы → Коммерческие
| Страница | Анкор | Цель |
|----------|-------|------|
| `blog/*`, `articles/*` | «Абонентское обслуживание» | `support.html` |
| `blog/*`, `articles/*` | «Сервер под ключ» | `servers.html` |
| `blog/*`, `articles/*` | «IT-аудит» | `audits/audit.html` |
| `sysadmin-cost-kazan.html` | «Рассчитать экономию» | `prices.html` |
| `compare/*` | «Тарифы F&F» | `prices.html` |

### Коммерческие → Сравнение / Кейсы / Калькулятор
| Страница | Анкор | Цель |
|----------|-------|------|
| `services.html` | «Сравнить с штатным» | `compare/ff-vs-staff-2026.html` |
| `services.html` | «Посмотреть кейсы» | `cases.html` |
| `support.html` | «Рассчитать стоимость» | `prices.html#calculator` |
| `servers.html` | «Кейс: сервер под ключ» | `cases/server-turnkey.html` |
| `prices.html` | «Сравнение с штатным» | `compare/compare.html` |

### Кейсы → Релевантные услуги
| Страница | Анкор | Цель |
|----------|-------|------|
| `cases/tobacco.html` | «Поддержка офиса» | `support.html` |
| `cases/tatar-septic.html` | «Сервер под ключ» | `servers.html` |
| `cases/server-turnkey.html` | «IT-аудит» | `audits/audit.html` |
| `cases/*` | «Все услуги» | `services.html` |

### Логические «следующие шаги»
В конце каждого важного блока добавлять 1–2 ссылки:
- После FAQ: «Не нашли ответ? Напишите в Telegram →»
- После кейсов: «Хотите такой же результат? Рассчитать стоимость →»
- После сравнения: «Посмотреть тарифы →»
- После процесса: «Заказать диагностику →»

## Реализация
- Добавить блок «Следующий шаг» в конце ключевых секций.
- Использовать класс `u-gold-underline` для визуального акцента.
- Не более 2–3 ссылок на блок.
