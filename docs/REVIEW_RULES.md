# Правила использования Review и AggregateRating — F&F Site

## 1. Только реальные отзывы
- Используйте только отзывы реальных клиентов, полученные с их согласия.
- Не выдумывайте отзывы и не публикуйте без согласия.
- Указывайте имя, должность, компанию (если разрешено) и дату.

## 2. Как правильно связывать отзыв с услугой/организацией
- Отзыв привязывается к `Service` или `Organization` через `itemReviewed`.
- Автор отзыва — `Person` с именем (можно анонимизировать по просьбе клиента).
- Оценка — `Rating` с `ratingValue` и `bestRating` (обычно 5).
- Текст отзыва — `reviewBody`.

## 3. Когда можно использовать AggregateRating
- Только при наличии **не менее 3–5 реальных отзывов**.
- AggregateRating указывает среднюю оценку и количество отзывов.
- Не использовать, если отзывов мало или они выдуманные.

## 4. Чего категорически нельзя делать
- ❌ Выдумывать отзывы и оценки.
- ❌ Использовать AggregateRating без реальных отзывов.
- ❌ Указывать оценку 5.0 при наличии негативных отзывов.
- ❌ Копировать отзывы с других сайтов без согласия.
- ❌ Использовать отзывы без согласия клиента.
- ❌ Завышать оценки (например, 4.9 при реальной 4.0).

## 5. Примеры корректной разметки

### Review (одиночный отзыв)
```json
{
  "@context": "https://schema.org",
  "@type": "Review",
  "itemReviewed": {
    "@type": "Service",
    "name": "IT-аутсорсинг F&F"
  },
  "author": {
    "@type": "Person",
    "name": "Директор, табачный магазин"
  },
  "reviewRating": {
    "@type": "Rating",
    "ratingValue": "5",
    "bestRating": "5"
  },
  "reviewBody": "F&F настроили сервер за один день. Раньше отчёты генерировались 10 минут, теперь 30 секунд. Рекомендую."
}
```

### AggregateRating (агрегированная оценка)
```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "IT-аутсорсинг F&F",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.9",
    "reviewCount": "5",
    "bestRating": "5",
    "worstRating": "1"
  }
}
```

## 6. Рекомендации для F&F
- Собирать реальные отзывы от клиентов (с согласия).
- Публиковать на сайте с указанием должности, компании, города, периода.
- Использовать Review schema только для реальных отзывов.
- AggregateRating — только при 5+ реальных отзывах.
- Мониторить отзывы на Яндекс.Картах, 2GIS, otzovik.
