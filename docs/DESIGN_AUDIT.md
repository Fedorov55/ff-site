# Design Audit — F&F Site

## 1. Текущее состояние
- 157 HTML-страниц, CSS: `css/style.css` ~123 KB, `css/critical.css` ~27 KB, `css/components.css`, `css/tokens.css`.
- Инлайн-стилей: 2212 (основной источник «разрозненности»).
- FAQ: стандартизированы классы `faq__list`, `faq__item`, `faq__question`, `faq__answer`.
- Хедер/футер: унифицированы, футер по эталону (3 колонки, центрирование, кнопки).
- Карточки услуг/проблем: иконки, фоновые цифры, золотые заголовки, белый текст, свечение при наведении.

## 2. Основные проблемы (на момент аудита)
1. Нет единой дизайн-системы: цвета/отступы/радиусы задаются прямо в HTML.
2. Дублирование CSS: одни и те же компоненты описаны несколько раз.
3. Инлайн-стили: 2212 вхождений.
4. Типографика: разные размеры/веса для одинаковых элементов.
5. Контент: на гео-страницах и кейсах мало текста.
6. Изображения: мало реальных скриншотов/схем.

## 3. Эталон
Эталонная страница: `services.html`. Полные правила — в `docs/ETALON.md`.

## 4. Фазы (выровнены по эталону)

### Фаза 1 — Дизайн-система ✅
- Токены (`css/tokens.css`), компоненты (`css/components.css`).
- Хедер/футер/карточки/FAQ/кнопки по эталону.
- Светлая тема через переменные.

### Фаза 2 — Единообразие шаблонов (текущая)
- Применить эталонные карточки (иконки, цифры, свечение) на всех страницах.
- Унифицировать секции: заголовки, карточки, списки, FAQ.
- Убрать инлайн-стили (заменить на классы из components.css).
- Проверить адаптивность на всех брейкпоинтах.

### Фаза 3 — Наполнение и контент
- Обогатить гео-страницы, кейсы, услуги: больше текста, выгоды, процесс, FAQ, цифры.
- Добавить реальные кейсы: проблема → решение → результат.
- Улучшить SEO-тексты (answer-first, AEO/GEO).
- Проверить тон.

### Фаза 4 — Визуальная полировка
- Подобрать качественные изображения, иконки, диаграммы.
- Микроанимации, hover/focus, скелетоны.
- Проверить контраст (WCAG AA) и обе темы.

### Фаза 5 — Производительность и SEO
- Core Web Vitals, оптимизация изображений/шрифтов/CSS/JS.
- Schema.org, sitemap, llms.txt.
- Проверка индексации и метатегов.

### Фаза 6 — QA и запуск
- Кросс-браузерное и мобильное тестирование.
- Lighthouse, Rich Results Test, консоль браузера.
- Финальный чек-лист и деплой.
