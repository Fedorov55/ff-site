# Краткое руководство: MCP, скиллы и инструменты (F&F)

## Что установлено (20 MCP, все бесплатные)

| Группа | Серверы | Для чего |
|--------|---------|----------|
| **Поиск** | Exa, web-search, ComputeFirst | Исследования, ключи, конкуренты |
| **Документация/код** | Context7, Serena, Codebase Memory, Repomix | Доки, навигация по коду, анализ зависимостей |
| **Браузер/аудит** | Playwright, Frontend Checklist, Desktop Commander | Автоматизация, аудит фронтенда, файлы/процессы |
| **Конвертация/скрейпинг** | MarkItDown, Scrapling, Crawl4AI | PDF/DOCX→MD, стелс-скрейпинг, краулинг |
| **Безопасность** | CVE Intelligence | CVE, CISA KEV, EPSS |
| **SEO** | SEO (iannuttall), OpenSEO | GSC/Bing/Analytics, платформа OpenSEO |
| **Утилиты** | Time, Memory | Время, долгосрочная память |

## Как пользоваться (3 шага)

1. **Выберите скилл** под задачу (см. таблицу ниже).
2. **Выберите инструменты** из матрицы.
3. **Ищите итеративно:** 2–4 запроса → чтение 2–4 источников → проверка → синтез с цитатами.

## Скиллы по задачам

| Задача | Скилл |
|--------|-------|
| Исследование конкурентов | `competitors` или `competitor-analysis` |
| Поиск ключей | `keywords` или `keyword-research` |
| SEO-аудит сайта | `seo-audit` (OpenSEO) |
| Поиск в интернете | `web-search` |
| Дизайн/фронтенд | `frontend-design`, `ui-ux-design-pro` |
| Code review | `review-team` |
| Справочник по MCP | `mcp-toolkit` |

## Быстрые команды

- `/mcps` — список MCP-серверов и вход (OAuth).
- `skill({ id: "..." })` — загрузить скилл.
- `execute({ code: "..." })` — вызвать инструменты MCP.

## Правила

- Ключи только через `{env:...}`, не в репо.
- Не вызывать все инструменты подряд — выбирайте минимальный набор.
- Context7 предпочтительнее web search для документации.
- Помечайте confidence: 🟢 проверено / 🟡 вероятно / 🔴 непроверено.
- Никогда не выдумывайте числа.
