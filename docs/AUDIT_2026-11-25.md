## 2. P0 — Critical

1. **15 landing/city pages canonicalize to homepage.** Files: almet.html, chelny.html, it-autsorsing-malyy-biznes.html, it-podderzhka-kazan.html, kompyuternaya-pomoshch-kazan.html, monitoring-serverov-kazan.html, nastroyka-seti-ofisa-kazan.html, nizhnekamsk.html, obsluzhivanie-kompyuterov-kazan.html, obsluzhivanie-serverov-kazan.html, rezervnoe-kopirovanie-kazan.html, sistemnyy-administrator-kazan.html, udalennyy-sisadmin-kazan.html, vosstanovlenie-dannykh-kazan.html, zelendolsk.html. Their `<link rel="canonical">` points to https://fedorov55.github.io/ff-site/ instead of self. Google will drop these pages from the index. Fix: self-canonical on each. (index.html canonical to homepage is correct.)
2. **16 pages share one meta description** ("IT-аутсорсинг для бизнеса 20-50 человек…") — the same 15 above plus index.html. Each landing page needs a unique description matching its intent.
3. **Desktop CLS 0.996** (Lighthouse). Culprits: `main#main`, `.skip-link`. Mobile CLS is 0, so this is viewport/layout specific. Investigate: skip-link transition (`top .3s`), font loading, sticky header height. This alone fails the CWV CLS ≤ 0.1 threshold on desktop.
4. **aria-prohibited-attr on `.quiz__progress`** (AccessLumens + Lighthouse): `<div class="quiz__progress" aria-label="Шаг 1 из 5">` — aria-label not allowed on a div without a role. Fix: remove aria-label (use visually hidden text or add role="group"/"progressbar" with proper attributes).

## 3. P1 — High

5. **Repeated identical links** (AccessLumens, name-repeated-controls): two "План действий →" and two "Что делать →" links in the pain-points section sound identical to screen readers. Add visually hidden item name after the visible text (keep visible words first; do not use aria-label that drops them — WCAG 2.5.3).
6. **Skip-link not recognized** (AccessLumens: keyboard-skip-link-missing): 12 focusable elements before `<main>`; the skip-link exists but is not detected as a working bypass (off-screen via top:-40px/-100px). Verify it actually moves focus to #main on activation; if not, fix target/href.
7. **Content outside landmarks** (AccessLumens, region, needs human review): 5 sections/content blocks (`.section.reveal` ×3, `.u-pt-0.section`, `a[rel="noopener noreferrer"]`) are not inside header/nav/main/footer. Wrap page sections in `<main>`/landmarks.
8. **Color contrast** (Lighthouse): mobile bottom bar button `.mobile-bottom-bar__btn--calc` (gold on light?) fails contrast. Check the gold-on-background pair.
9. **Render-blocking CSS** (Lighthouse mobile): `css/critical.css?v=130` blocks render; estimated 300 ms LCP/FCP savings. Inline critical CSS or defer.
10. **Cache lifetimes** (Lighthouse): `style.css`, two JetBrains Mono woff2 files have no long cache (GitHub Pages defaults). _headers (Cloudflare) is not applied on GitHub Pages. Either deploy to Cloudflare Pages or set cache via service worker. Est. 132 KiB / 150 ms savings.
11. **Forced reflow** (Lighthouse desktop): `js/script.js` queries geometric properties after DOM mutations. Refactor to batch reads/writes.
12. **Images not responsive** (Frontend Checklist): 3 images without srcset/sizes. Add srcset (400w/800w/1200w) + sizes.
13. **Long titles** (OpenSEO): contacts.html (65), obsluzhivanie-kompyuterov-kazan.html (65), obsluzhivanie-serverov-kazan.html (62), support.html (75) exceed 60 chars. Trim.
14. **Long meta description** (OpenSEO): prices.html (169 chars) exceeds 160. Trim.
15. **Duplicate title**: infrastructure/mail-server.html and services/mail.html share "Почтовый сервер за 15 мин в Казани…". Differentiate or canonicalize one to the other.
16. **Case pages canonicalize to sibling**: cases/case-incident-saturday.html → backup-recovery.html; cases/case-vs-staff.html → office-support.html. Verify intentional (duplicate content) or fix to self.
17. **Two case pages share a description** (case-vs-staff.html, office-support.html). Differentiate or canonicalize.
