# Чек-листы ссылочного профиля — F&F Site

## 1. Опасный профиль (риск Минусинска)

### Признаки опасного профиля
- [ ] Анкоры с точным вхождением ключа («купить сервер Казань», «IT-аутсорсинг Казань цена») — более 30% ссылок.
- [ ] Ссылки с сайтов-каталогов, досок объявлений, бирж ссылок.
- [ ] Резкий рост ссылок за короткий период (сотни за месяц).
- [ ] Ссылки с сайтов другой тематики (казино, фарма, adult).
- [ ] Доноры с низким трафиком и высоким спам-скором.
- [ ] Ссылки с одинаковым анкором с десятков доменов.
- [ ] Отсутствие nofollow/sponsored у рекламных ссылок.
- [ ] Ссылки из футеров/сайдбаров на всех страницах донора.
- [ ] Домены-доноры с короткой историей (менее 1 года).
- [ ] Покупные ссылки с бирж (Sape, GoGetLinks и т.п.).

### Что делать при обнаружении
1. Проанализировать профиль в Яндекс.Вебмастер → «Ссылки».
2. Отклонить токсичные ссылки через Disavow (если есть доступ).
3. Удалить покупные ссылки.
4. Снизить долю точных анкоров до <15%.
5. Добавить естественные ссылки (упоминания, отзывы, партнёры).

## 2. Здоровый естественный профиль (для небольшой IT-компании из региона)

### Признаки здорового профиля
- [ ] Доля точных ключевых анкоров — менее 15%.
- [ ] Доля брендовых анкоров («F&F», «fedorov55», «Фатхутдинов») — 40–60%.
- [ ] Доля естественных анкоров («здесь», «тут», «по ссылке», URL) — 20–30%.
- [ ] Доноры — тематические (IT, бизнес, региональные) сайты.
- [ ] Ссылки из контента (статьи, отзывы, кейсы), а не из футеров/сайдбаров.
- [ ] Постепенный рост ссылок (5–15 в месяц).
- [ ] Доноры с реальным трафиком и историей > 2 лет.
- [ ] Региональные ссылки (Казань, Татарстан) — 30–50%.
- [ ] Отзывы и упоминания на Яндекс.Картах, 2GIS, otzovik и т.п.
- [ ] Ссылки из соцсетей (Telegram, VK, Habr) — естественные.

### Источники естественных ссылок для F&F
- Региональные бизнес-каталоги (Казань, Татарстан).
- Партнёрские страницы (поставщики, клиенты).
- Отзывы на Яндекс.Картах, 2GIS, otzovik, Яндекс.Услуги.
- Публикации на Habr, vc.ru, Pikabu (с реальным контентом).
- Упоминания в локальных СМИ и блогах.
- Ссылки из соцсетей (Telegram-канал, VK-группа).
- Кейсы и исследования на собственном блоге (привлекают естественные ссылки).

### Рекомендуемая стратегия
1. **Не покупать ссылки.** Всё — органически.
2. **Публиковать кейсы и исследования** — они привлекают естественные ссылки.
3. **Работать с отзывами** — Яндекс.Карты, 2GIS, otzovik.
4. **Партнёрство** — ссылки с сайтов клиентов/поставщиков.
5. **Мониторинг** — Яндекс.Вебмастер → «Ссылки» ежемесячно.
