# Аудит первого экрана — F&F Site

## Общие критерии
- Понятно за 3 секунды: что предлагают и кому.
- Один доминирующий CTA above the fold.
- Минимум отвлекающих элементов.
- Сильный оффер с цифрой.

## Страницы

### index.html
- **Понятно за 3 сек:** Да. Hero: «IT-инфраструктура для бизнеса», оффер с цифрами.
- **Доминирующий CTA:** «Рассчитать стоимость» (primary).
- **Отвлекает:** фоновые анимации, terminal-блок.
- **Рекомендация:** Упростить hero, убрать terminal из первого экрана.
