# GEO / AI Visibility — F&F Site

## Почему видимость в Алисе и AI Overviews зависит от топа выдачи
- «Поиск с Алисой» и AI Overviews (Google) строят ответы на основе страниц из топ-10 обычной выдачи.
- Если страница не в топ-10, ИИ почти не цитирует её.
- Поэтому первый шаг — классическое SEO (контент, структура, скорость, ссылки), а уже поверх — AEO/GEO-оптимизация.

## Приоритетный порядок работ

### 1. Первый приоритет (без этого ничего не работает)
- Контент: углубить тексты, добавить цифры, кейсы, FAQ.
- Структура: чёткие заголовки, списки, таблицы.
- Скорость: Core Web Vitals, оптимизация изображений/шрифтов.
- Ссылки: естественные упоминания, отзывы, партнёры.
- **Цель:** попасть в топ-10 по ключевым запросам.

### 2. Второй приоритет (усиление после попадания в топ-10)
- Answer-first абзацы (короткий прямой ответ на вопрос).
- FAQPage schema (вопросы и ответы).
- BreadcrumbList, Service, HowTo schema.
- llms.txt — структурированное описание для ИИ.
- Цитируемые фрагменты (2–3 предложения с конкретными цифрами).

### 3. Третий приоритет (тонкая настройка)
- Оптимизация под конкретные фразы Алисы («сколько стоит сисадмин в Казани»).
- Добавление отзывов и кейсов с реальными цифрами.
- Мониторинг цитирования в ИИ-ответах.
- A/B-тесты сниппетов для роста CTR.
