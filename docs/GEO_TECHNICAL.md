# Технические элементы для генеративного поиска — F&F

## 1. llms.txt
- **Что:** Структурированное описание сайта для ИИ-систем.
- **Статус:** Есть, обновлён с новыми страницами.
- **Влияние:** Среднее. Помогает ИИ понять структуру, но не заменяет SEO.
- **Рекомендация:** Держать актуальным, добавлять новые страницы.

## 2. robots.txt
- **Что:** Правила для краулеров.
- **Статус:** Настроен, разрешает всех ботов (GPTBot, ClaudeBot и др.).
- **Влияние:** Высокое. Без правильного robots.txt ИИ-краулеры не зайдут.
- **Рекомендация:** Оставить как есть, разрешать всех ботов.

## 3. Schema.org
- **Что:** Структурированные данные (Organization, Service, FAQPage, BreadcrumbList, Person, Review, HowTo).
- **Статус:** Добавлено на 156 из 161 страниц.
- **Влияние:** Высокое. Помогает ИИ извлечь факты и цитировать.
- **Рекомендация:** Добавить на оставшиеся страницы (404, legal).

## 4. Чистота HTML
- **Что:** Семантическая разметка, правильные теги, отсутствие мусора.
- **Статус:** Удалены инлайн-стили, дубли блоков, плейсхолдеры.
- **Влияние:** Среднее. Чистый HTML легче парсить ИИ.
- **Рекомендация:** Поддерживать чистоту, использовать семантические теги.

## 5. Скорость и мобильность
- **Что:** Core Web Vitals, адаптивность, lazy loading.
- **Статус:** LCP/INP/CLS в норме, lazy loading на всех изображениях.
- **Влияние:** Высокое. Медленные страницы не индексируются и не цитируются.
- **Рекомендация:** Оптимизировать изображения (WebP/AVIF), подсетить шрифты.

## Что реально влияет vs вторично

| Фактор | Влияние | Статус |
|--------|---------|--------|
| robots.txt | Высокое | ✅ Готово |
| Schema.org | Высокое | ✅ 156/161 |
| Скорость (CWV) | Высокое | ✅ В норме |
| llms.txt | Среднее | ✅ Обновлён |
| Чистота HTML | Среднее | ✅ Убран мусор |
| Мобильность | Высокое | ✅ Адаптивно |

## Вывод
- **Критичные:** robots.txt, Schema.org, скорость, мобильность.
- **Важные:** llms.txt, чистота HTML.
- **Вторичные:** точная структура llms.txt (ИИ читает, но не критично).
