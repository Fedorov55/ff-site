# Мобильный первый экран — F&F

## Что должно быть видно без прокрутки (above the fold)
1. **Главный месседж** — H1 + 1 строка подзаголовка (не более 2 строк).
2. **Один CTA** — primary кнопка («Рассчитать стоимость» или «Позвонить»).
3. **Ключевая цифра** — «от 10 000 ₽/мес» или «SLA 99.5%».

## Что прятать/переносить ниже на мобильном
- **Terminal** — убрать с первого экрана, перенести в блок «Как мы работаем».
- **Hero__metrics** (4 метрики) — перенести в секцию «Результаты в цифрах».
- **Hero__features** (список преимуществ) — сократить до 2 пунктов или перенести ниже.
- **Hero__brandbar** — перенести ниже или убрать.
- **Вторичный CTA** — оставить только если помещается, иначе в sticky bottom bar.

## CSS-рекомендации
```css
@media (max-width: 639px) {
  .hero__title { font-size: clamp(32px, 9vw, 44px); line-height: 1.1; }
  .hero__lead { font-size: 15px; max-width: 100%; }
  .hero__buttons { flex-direction: column; }
  .hero__buttons .btn { width: 100%; }
  .hero__visual { display: none; } /* terminal убираем */
  .hero__metrics { display: none; }
  .hero__brandbar { display: none; }
}
```

## Приоритет
1. **Высокий:** Убрать terminal и metrics с первого экрана на мобильном.
2. **Высокий:** Один CTA на всю ширину.
3. **Средний:** Сократить hero__lead до 1 предложения.
4. **Низкий:** Добавить sticky bottom bar с «Позвонить» и «Рассчитать».
