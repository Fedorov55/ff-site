# A/B-тесты первого экрана — F&F

## 1. Заголовок: результат vs вопрос
- **A:** «IT-инфраструктура для бизнеса» (утверждение)
- **B:** «Сколько стоит IT-поддержка для вашего офиса?» (вопрос)
- **Измеряем:** CTR, время на странице, конверсия.

## 2. Главный CTA: «Рассчитать стоимость» vs «Позвонить»
- **A:** Primary CTA «Рассчитать стоимость»
- **B:** Primary CTA «Позвонить +7 (901) 265-52-52»
- **Измеряем:** Конверсия, клики по телефону, заявки.

## 3. С терминалом vs без терминала
- **A:** Hero с terminal-блоком (анимация сценариев)
- **B:** Hero без terminal (только текст и CTA)
- **Измеряем:** Время на странице, глубина скролла, отказы.

## 4. Акцент на экономию vs на скорость
- **A:** Hero с акцентом «Экономия до 80%»
- **B:** Hero с акцентом «Реакция 15 минут»
- **Измеряем:** CTR, конверсия, время на странице.

## 5. Один CTA vs два CTA
- **A:** Один primary CTA («Рассчитать стоимость»)
- **B:** Два CTA (primary «Рассчитать» + ghost «Позвонить»)
- **Измеряем:** Конверсия, клики, отказы.
