# Deploy Checklist — F&F IT

## Критично (перед каждым деплоем)

- [ ] Формы реально отправляются (не YOUR_FORM_ID и не заглушки)
- [ ] Нет PLACEHOLDER / YOUR_ / 00000000 в коде
- [ ] Canonical указывает на `https://fedorov55.github.io/ff-site/`
- [ ] robots.txt и sitemap.xml соответствуют основному домену
- [ ] CSP не блокирует нужные скрипты и стили
- [ ] Нет noindex на продакшен-страницах (сейчас noindex на всех — staging)

## Контент и вёрстка

- [ ] Нет пустых секций (empty sections)
- [ ] Нет явных незаполненных блоков и lorem
- [ ] Ключевые цифры совпадают (цены, 120+, 99,5% и т.д.)
- [ ] 404-страница работает и отдаёт 404

## Техника

- [ ] Версии CSS/JS обновлены (сейчас v=106)
- [ ] Шрифты локальные
- [ ] Основные страницы открываются без ошибок в консоли
- [ ] Якорные ссылки скроллят корректно (scroll-margin-top: 96px)

## После деплоя

- [ ] Проверить главную, support, servers, contacts, 404
- [ ] Проверить отправку одной тестовой формы
- [ ] Проверить sitemap.xml и robots.txt отдаются

## Команды

```bash
# Проверка сайта
python scripts/check-site.py

# Генерация sitemap
python scripts/generate-sitemap.py

# Проверка JS
node --check script.js
node --check calculator.js
```

## Регламент

- **Перед каждым деплоем** — быстрая проверка (check-site.py)
- **Раз в месяц** — полная проверка всех внутренних ссылок
- **После добавления большого числа новых страниц** — обязательная проверка
